# 🎣 瑪奇 Mobile 自動釣魚助手 (Mabinogi Mobile Fishing Bot)

這是一個專為《瑪奇 Mobile》設計的智慧型自動釣魚輔助工具。專案採用 **OpenCV 彩色影像辨識** 與 **mss 顯示卡級高速螢幕擷取** 技術，結合現代化的 **CustomTkinter GUI 介面**，內建雙重智慧收線、滑鼠自動歸位以及強大的防斷線重整機制，在掛機的同時完全不干擾你日常使用電腦。

---

## ✨ 核心特色

- **🎨 現代化 GUI 最上層顯示**：使用 `customtkinter` 打造，設定流程直覺，視窗預設保持在最上層（Topmost），方便對照遊戲調整。
- **📊 雙重智能收線機制**：
  - **機制 A（彩色圖示辨識）**：採用三通道彩色 Template Matching 演算法，精準比對彈出的 Space 收線圖示，完全杜絕傳統灰階辨識誤認純綠色按鈕的問題。
  - **機制 B（綠條轉折偵測）**：動態追蹤進度條像素變化，精準鎖定「向左縮短」剛轉為「向右增加」的物理轉折點，並內建真人隨機反應延遲（0.1~0.5秒）。
- **🖥️ 視窗標題精準測試**：UI 內建「測試切換」按鈕，採用「完全匹配」演算法，能一鍵驗證 Python 是否成功聚焦模擬器，完美避開瀏覽器 Google 搜尋分頁等模糊標題的干擾。
- **⏰ 30秒閒置喚醒防斷線**：若連續 30 秒未偵測到任何釣魚動作（如卡住或斷線），會自動將指定標題的模擬器視窗還原並聚焦至最上層，自動按下 `W` 鍵重整狀態。
- **🧘‍♂️ 滑鼠點擊自動歸位**：所有收線點擊與防斷線重整動作執行後，滑鼠游標會以毫秒級速度**移回使用者原本游移的位置**，讓你邊掛機邊看網頁、工作也完全不被偷走焦點。
- **💾 設定自動持久化**：不論是視窗標題、辨識區域、按鈕座標或緩衝閥值，設定完成後皆會自動寫入 `config.json`，下次開啟「一鍵即用」。
- **🔕 全域防鎖緊急停止**：內建全域快捷鍵 **`Ctrl + Alt + Q`**，在任何視窗下按下皆能在毫秒內對腳本緊急剎車並安全釋放滑鼠。
- **🏷️ 版本可視化管理**：介面右下角即時顯示當前版本號（如 `v.4.1`），方便多版本打包管理與分發追蹤。

## 🛠️ 環境安裝與打包指南 (Installation & EXE Compilation)

本專案支援在 Python 原始碼環境下執行，亦可透過 PyInstaller 編譯成不需 Python 環境即可獨立運行的 `.exe` 執行檔。

---

### 1. Python 開發環境安裝 (Python Environment Setup)

請確保你的電腦已安裝 **Python 3.10 或以上版本**，並於專案目錄下執行以下指令安裝所需核心依賴庫：

```bash
pip install customtkinter opencv-python numpy mss pyautogui keyboard pygetwindow pillow pyinstaller
```

> ⚠️ **管理員權限提示**：由於 `keyboard` 庫需要監聽系統的全域鍵盤事件，不論是執行 `.py` 原始碼或最終的 `.exe` 檔案，皆建議以 **「系統管理員身分」** 執行終端機（PowerShell / CMD）或執行檔，否則緊急停止快捷鍵（`Ctrl + Alt + Q`）可能會失效。

---

### 2. 編譯成獨立 EXE 執行檔 (EXE Compilation Guide)

若要將腳本打包成雙擊即可運行的 Windows 執行檔，請遵循以下步驟：

#### 📝 步驟 A：修改程式碼中的資源路徑（打包必做）
為確保程式轉換成 `.exe` 後，在臨時解壓路徑或不同目錄下仍能精準讀寫 `config.json` 與 `fish_icon.png`，請務必確認你的 `auto_fishing.py` 頂部的檔案路徑定義已使用以下**動態絕對路徑**：

```python
import os
import sys

# 取得目前 .py 原始碼或編譯後 .exe 檔所在的實際資料夾絕對路徑
BASE_DIR = os.path.dirname(os.path.abspath(sys.argv[0]))

CONFIG_FILE = os.path.join(BASE_DIR, "config.json")
ICON_PATH = os.path.join(BASE_DIR, "fish_icon.png")
```

#### 💻 步驟 B：執行 PyInstaller 打包指令
打開具有管理員權限的終端機，切換至專案根目錄，執行以下指令：

```bash
pyinstaller --noconfirm --onedir --windowed --name "mabi_fish_bot" .\auto_fishing.py
```

* **參數說明**：
  * `--onedir`：將 `.exe` 與依賴環境（OpenCV / CustomTkinter 的 DLL 等）打包至同一個資料夾。此模式對圖形辨識腳本**最穩定，且啟動速度最快**。
  * `--windowed`：運行程式時**隱藏黑色的 CMD 控制台視窗**，只呈現精美的藍色 GUI 介面。
  * `--name`：指定生成的執行檔與輸出資料夾名稱。

#### 📦 步驟 C：獲取與部署產出物
1. 打包完成後，專案目錄下會生成一個 `dist/` 資料夾。
2. 進入 `dist/mabi_fish_bot/` 即可找到 `mabi_fish_bot.exe`。
3. **重要手續**：請將你原先裁剪好的 `fish_icon.png` 或歷史 `config.json` **手動複製一份放入這個帶有 `.exe` 的資料夾內**。
4. 之後只需將整個 `mabi_fish_bot/` 資料夾壓縮，即可隨意分發至其他未安裝 Python 的 Windows 電腦上完美運行。

## 📖 詳細操作使用說明 (Detailed Operation Instructions)

### 📌 步驟 1：啟動程式 (Launching the Program)

為了確保程式能順利監聽全域快捷鍵（`Ctrl + Alt + Q`），並且有權限控制與聚焦模擬器視窗，**不論是執行 Python 原始碼或執行編譯後的 EXE，都必須使用「系統管理員身分」啟動**：

#### 💡 情況 A：使用 Python 原始碼執行
1. 在 Windows 開始功能表搜尋 `PowerShell` 或 `命令提示字元 (CMD)`。
2. 對其點選滑鼠右鍵，選擇 **「以系統管理員身分執行」**。
3. 在彈出的管理員終端機中，使用 `cd` 指令切換至專案目錄：
   ```bash
   cd {project_location}
   ```
4. 輸入以下指令啟動程式：
   ```bash
   py .\auto_fishing.py
   ```

#### 💡 情況 B：使用編譯後的 EXE 執行
1. 開啟打包產出的資料夾 `dist/mabi_fish_bot/`。
2. 找到 `mabi_fish_bot.exe` 檔案。
3. 對其點選滑鼠右鍵，選擇 **「以系統管理員身分執行」**。
4. *(選做)* 為了以後方便，你可以對該 `.exe` 點選右鍵 -> `內容` -> 切換到 `相容性` 頁籤 -> 勾選 **「以系統管理員的身分執行此程式」** -> 點擊 `確定`。之後每次雙擊開啟就會自動以管理員權限運行。

---

### 📌 步驟 2：核心掛機設定（初次使用）

請先開啟你的遊戲，並進入釣魚準備狀態：

1. **遊戲視窗標題測試**：
   - 在最上方的輸入框輸入你的遊戲精確標題（例如：`瑪奇 Mobile`）。
   - 點擊橘色的 `測試切換` 按鈕，確認遊戲是否有被成功拉到最上層，且日誌顯示 `✅ 成功聚焦視窗！`。
2. **設定釣魚辨識區域 (綠條)**：
   - 點擊 `1. 設定釣魚辨識區域 (綠條)`。
   - 螢幕會瞬間凍結，請按住滑鼠左鍵，**精準框選釣魚小遊戲中上方那條綠色安全進度條會來回移動的範圍**，完成後按 **Enter** 儲存。
3. **擷取開始釣魚圖示範本**：
   - 前往釣魚區
   - 點擊 `1.5 擷取開始釣魚圖示範本`。
   - 畫面凍結後，請精準**框選該開始釣魚圖示的核心花紋與色彩區塊**，完成後按 **Enter**。程式會將其存為彩色的 `fish_icon.png`。
4. **設定收線按鈕位置**：
   - 點擊 `2. 設定收線按鈕位置`。
   - 介面會開始倒數 3 秒，請在這 3 秒內將**滑鼠游標移到模擬器中右下角「收線/點擊」按鈕的正中央**並停住。倒數結束即自動鎖定座標。

> ✨ **提示**：以上設定完成後會自動寫入 `config.json`。未來重新開啟程式時會自動顯示 `已載入 ✔`，可跳過此步驟直接啟動。

---

### 📌 步驟 3：微調與測試辨識（強烈建議）

1. 在介面上勾選橘色的 **「停用點擊動作（僅測試辨識日誌）」**。
2. 點擊綠色的 `▶ 啟動腳本`。
3. 手動或放任遊戲釣魚，並觀察 **📋 執行日誌 (Action Log)**：
   - 當綠色條向左縮短時，應顯示 `📉 綠色條正在向左縮短...`。
   - 當彈回來的瞬間，應顯示 `🔬 [測試] 偵測到轉折！...`。
   - 如果**還在向左縮短時就提前誤觸了轉折日誌**：請調大介面上的 `3. 轉折緩衝門檻 (PIXEL_BUFFER)`（例如從 15 改為 25 或 35），並按下「儲存設定」即可即時套用，直到日誌能完美同步轉折點。

---

### 📌 步驟 4：正式開始全自動釣魚

1. 取消勾選 **「停用點擊動作」**。
2. 點擊綠色的 `▶ 啟動腳本`（按鈕會變為紅色的 `🔕 停止腳本`）。
3. 程式正式開啟全自動釣魚！此時你可以放心地將模擬器丟在背景，照常切換到瀏覽器看影片或處理其他工作。

---

### 📌 步驟 5：隨時停止

- **方法 A**：直接點擊程式介面上的紅色 `🔕 停止腳本` 按鈕。
- **方法 B (最安全)**：在任何視窗焦點下，直接在鍵盤按下 **`Ctrl + Alt + Q`**，腳本會透過全域監聽在毫秒之內緊急剎車並安全釋放滑鼠。

## 🛠️ 常見問題排查 (Troubleshooting)

| 現象 | 原因 | 解決方法 |
| :--- | :--- | :--- |
| **聚焦視窗時，抓到了瀏覽器的 Google 搜尋分頁** | 視窗標題名稱過於模糊或重疊 | 請勿直接使用「瑪奇 Mobile」這類容易出現在瀏覽器標題的關鍵字。請將 UI 頂部的視窗標題直接改填模擬器的原生標題。 |
| **點擊設定按鈕 1 或 1.5 時程式崩潰** | 多螢幕導致的 mss 座標列表錯誤 | 本腳本預設支援主顯示器。如果是多螢幕，請將遊戲模擬器移至「主螢幕 (Primary Monitor)」上執行再進行設定。 |
| **綠條移動時 Action Log 完全沒反應** | 模擬器開啟了濾鏡、夜間護眼模式或畫質太低 | 護眼模式會改變畫面的 HSV 色域。請關閉模擬器的護眼濾鏡，或調高遊戲畫質，確保綠色條顏色飽和鮮明。 |
| **閒置防斷線觸發時提示 `視窗切換失敗`** | 執行緒找不到指定標題的視窗 | 請確保遊戲在掛機過程中沒有被意外關閉，且 UI 最上方的視窗標題輸入框與你當前運行的遊戲標題完全一致。 |
